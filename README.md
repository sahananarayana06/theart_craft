# 🎨 The Art Craft

A full-stack handmade crafts and artwork web application built with **HTML, CSS, JavaScript, Node.js, Express.js, and SQLite**.

The Art Craft provides a beautiful platform to showcase handmade products, allow customers to explore products, submit reviews, and contact the seller through WhatsApp. It also includes an admin panel for managing products, images, and reviews.

---

## ✨ Features

### 🛍️ Customer Features

- Browse handmade craft products
- View product details
- Search products
- Filter products by category
- Responsive product gallery
- Customer reviews and ratings
- Submit product reviews
- WhatsApp-based product ordering
- Contact the seller
- Responsive design for desktop, tablet, and mobile

### 🔐 Admin Features

- Secure admin verification
- Add new products
- Edit existing products
- Delete products
- Upload product images
- Manage customer reviews
- Delete reviews
- Product category management
- Product price and description management

---

## 🛠️ Technologies Used

### Frontend

- **HTML5** – Website structure
- **CSS3** – Styling, responsive design and animations
- **JavaScript (Vanilla JS)** – Client-side functionality
- **Font Awesome** – Icons
- **Google Fonts** – Typography

### Backend

- **Node.js** – JavaScript runtime
- **Express.js** – Backend server and REST API
- **Multer** – Image upload handling

### Database

- **SQLite3** – Lightweight relational database

### Development Tools

- **Visual Studio Code**
- **Git**
- **GitHub**
- **Cloudflare Tunnel** – Temporary public testing
